# VisionPoint Landing Page Component Variations

This folder contains a modular HTML library of reusable landing page components designed for VisionPoint Marketing. These components follow modern best practices for accessibility, responsiveness, and performance using Bootstrap 5.3.

## 📁 Folder Structure

Each `.html` file represents a group of related layout variations commonly used on higher ed landing pages.

| File Name                              | Component Group                          |
|----------------------------------------|------------------------------------------|
| `hero-sections.html`                   | Hero Section Variations                  |
| `intro-value-variations.html`          | Intro / Value Proposition Sections       |
| `lead-form-blocks.html`                | Lead Form Blocks                         |
| `programs-areas-of-study.html`         | Programs / Areas of Study Modules        |
| `testimonial-variations.html`          | Student Testimonial Sections             |
| `stats-outcomes-variations.html`       | Stats + Outcomes Modules                 |
| `video-embed-modules.html`            | Video Embed Modules                      |
| `process-timeline-variations.html`     | Process / Timeline Sections              |
| `faq-accordion-sections.html`          | FAQ / Accordion Layouts                  |
| `location-modality-modules.html`       | Location / Modality Information          |
| `contact-advisor-info-variations.html` | Contact / Advisor Info Modules           |
| `trust-accreditation.html`             | Trust / Accreditation / Partner Logos    |

---

## 🚀 How to Use

1. Open `index.html` in a browser to browse all layout modules visually.
2. Click any component group to view its layout variations.
3. Copy and paste the desired sections into your landing page build (Breakdance, Elementor, or raw HTML).
4. Replace placeholder images and text with your actual content.
